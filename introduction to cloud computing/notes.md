# Introduction to Cloud Computing

## What is Cloud Computing?

Cloud computing is the delivery of computing services such as storage, servers, databases, networking, and software over the internet.

### Key Advantages

- On-demand access to computing resources
- Reduced infrastructure costs
- Scalability based on demand
- Accessibility from different locations and devices

## Cloud Service Models

### IaaS – Infrastructure as a Service

IaaS provides virtualized computing infrastructure over the internet. It is similar to renting computing resources instead of purchasing and maintaining physical infrastructure.

**You manage:**
- Applications
- Data
- Operating system

**The cloud provider manages:**
- Physical servers
- Storage infrastructure
- Networking
- Virtualization

**Advantages**
- Provides greater control and flexibility over computing resources.
- Reduces the cost of purchasing and maintaining physical hardware.
- Resources can be scaled up or down based on demand.
- Users only pay for the resources they use.

**Disadvantages**
- Requires more technical knowledge to manage.
- Users are responsible for managing the operating system and applications.
- Incorrect configuration can create security risks.
- Costs can increase if resources are not properly monitored.

### PaaS – Platform as a Service

PaaS provides a platform that allows developers to build, test, and deploy applications without managing the underlying infrastructure.

**You manage:**
- Applications
- Data

**The cloud provider manages:**
- Operating system
- Servers
- Networking
- Runtime
- Middleware

**Advantages**
- Allows developers to focus mainly on application development.
- Reduces the need to manage servers and infrastructure.
- Makes application development and deployment faster.
- Supports easy scalability.

**Disadvantages**
- Provides less control over the underlying infrastructure.
- Developers may depend heavily on the cloud provider's platform.
- Some platforms may have limitations on supported programming languages or tools.
- Moving an application from one provider to another can sometimes be difficult.



### SaaS – Software as a Service

SaaS delivers ready-to-use software over the internet, usually through a subscription.

**You manage:**
- User settings
- Your data

**The cloud provider manages:**
- The application
- Infrastructure
- Maintenance and updates

**Advantages**
- Easy to access through the internet.
- Does not require users to install or maintain complex software.
- The provider handles updates and maintenance.
- Can be accessed from different devices and locations.
- Usually has lower initial costs.

**Disadvantages**
- Requires a reliable internet connection.
- Users have limited control over the software and infrastructure.
- Data privacy and security depend partly on the cloud provider.
- Subscription costs may increase over time.
- Service availability depends on the provider.

### Key Takeaway
 The main difference between IaaS, PaaS, and SaaS is the level of responsibility shared between the user and the cloud provider.
 IaaS provides the greatest level of control but also requires more management.
 PaaS provides a managed environment for developing and deploying applications.
 while SaaS provides ready-to-use software with the least management responsibility for the user.
